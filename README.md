# Overload — progressive overload tracker

A small, offline-first PWA for logging weight × reps per exercise or machine and
watching the numbers go up. Built with React 19, TypeScript, Vite and zustand.

## Features

- 219 built-in exercises and machines, each with start / end illustrations, a front and back
  body map of the target muscles, and step-by-step instructions, or add your own
- Every exercise has a recommended sets × rep range (e.g. squat 4 × 5–8, lateral raise 3 × 12–20);
  custom exercises pick a goal (Strength / Muscle / Isolation / Endurance) or an exact range
- Log a session as a list of sets (weight × reps) with +/− steppers
- Smart suggestion for the next session (double progression: add reps until every set hits the
  top of the range, then add 2.5 kg / 5 lb and drop back to the bottom)
- Per-exercise stats: last top set, best weight, estimated 1RM
- Progress chart (top set, est. 1RM or volume) with hover/touch tooltip
- History with PR badges, edit and delete
- kg / lb, JSON export & import, works fully offline, installable to the home screen

```

```

## Deploy to GitHub Pages

1. Create a GitHub repository and push this project to the `main` branch.
2. In the repo go to **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Every push to `main` runs `.github/workflows/deploy.yml`, which builds with
   `VITE_BASE=/<repo-name>/` and publishes `dist/`.

The app will be served at `https://<user>.github.io/<repo-name>/`.
If you build locally for a repo that is not called `progressive-overload`, set
`VITE_BASE=/your-repo-name/ npm run build`.

All data is stored in the browser (`localStorage`). Use **Settings → Export** to back it up.

## Exercise library

`src/data/presets.ts`, `src/data/instructions.ts` and `public/exercises/*` are generated by
`scripts/build-exercises.mjs`:

- Illustrations (start / end pose, 3D-rendered figure) come from
  [open-exercise-illustrations](https://github.com/hitmanrepo/open-exercise-illustrations) (CC0 public domain),
  which also supplies the primary / secondary muscles shown on the body map.
- Step-by-step instructions come from [free-exercise-db](https://github.com/yuhonas/free-exercise-db)
  (public domain), with a few written for this app.
- The body map is [react-body-highlighter](https://github.com/giavinh79/react-body-highlighter) (MIT).

To add or re-tune exercises, edit the curated list at the top of the script and run:

```bash
npm run build:exercises        # add --skip-images to only regenerate the TS files
```

Illustrations are resized to 480 px WebP (about 5 KB each, under 2 MB total) and precached by the
service worker, so the whole library works offline after the first visit.
